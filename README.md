## 1. 原版已有功能（速览）

| 类目 | 工具（52 个） |
|---|---|
| **外贸沟通**（6） | 外贸邮件话术库、外贸询盘优先级评估、信用证交单自查清单、催款邮件生成器、信用证远期贴现计算器、收款方式风险速查 |
| **物流与装柜**（12） | 装箱单生成器、装柜/箱规计算器、托盘装载计算器、空运/快递计费重计算器、海运费用拆分、滞箱滞港费、报关费用估算、国际快递报价对比、出口保险费、FOB/CIF 货代收费核对、纸箱包装方案对比、外贸单位换算 |
| **财务报价**（13） | 报价利润计算器、阶梯报价计算器、订单保本销量、降价保利销量、供应商报价对比、收款账期成本、汇率敏感性分析、出口退税计算器、进口到岸成本、阶梯佣金、人民币大写转换、数字转英文、货币符号大全 |
| **文件与格式转换**（7） | 商业发票/形式发票生成器、外贸唛头生成器、国际条码生成器、JSON 格式化与转换、YAML↔JSON、CSV↔Markdown 表格、产品图片压缩 |
| **国家与货币**（4） | 全球国家信息查询、目标市场电压与插头、国际收款渠道费用对比、多币种报价换算 |
| **时间与节假日**（4） | 世界时间、国际节假日查询、外贸交期计算器、Unix 时间戳转换 |
| **文本处理**（4） | 英文大小写转换、中文转拼音、特殊字符检查与转换、外贸邮件签名生成器 |
| **VPS/站长工具**（2） | VPS 剩余价值计算器、服务器成本对比 |

> 原版共 52 个工具，其中「VPS/站长工具」2 个（原版还把 Unix 时间戳转换归在这一类）；本项目新增「外贸术语库」、移除站长工具 2 个，合计 51 个。

## 2. 相对原版的改动（13 条）

| 改动 | 说明 |
|---|---|
| **1080p 单屏化适配** | 工具页统一「统计条 + 左右两栏 + 长文折叠 + 表格内滚动」，一屏装下参数与结果，覆盖 7 类目 40+ 页面，每页单独调比例 |
| **可拖拽的悬浮搜索球** | 侧边悬浮，可拖动吸附、记住位置、可收起再唤回 |
| **2K / 4K 自动放大** | ≥2200px 时工具页放大到 1.25 倍，1080p 不变，打印自动还原 |
| **页面布局整体优化** | 首页卡片放松、首页一排 3 个、相关工具一排 5 个、去掉多余推广卡 |
| **打印 A4 版式** | 装箱单 / 发票按 A4 单据排版，打印时隐藏站点元素并取消缩放 |
| **字号统一** | 去掉各工具页自带的字体调节控件，全站默认最大字号 |
| **外贸术语库（新增）** | 505 条术语 + 31 条邮件句式 + 100 个缩写 + 11 条 Incoterms；四视图检索、单条复制、可下载 Excel |
| **我的收藏** | 术语库条目可星标，支持「只看收藏」「导出收藏 CSV」（存本地浏览器） |
| **国际贸易术语并入术语库** | 原独立页面取消，改为术语库第 2 个视图；旧链接 301 跳转 |
| **发票 / 装箱单 / 条码重做** | 发票四字段 2×2 对齐、字号调小、下拉不再截断；装箱单 A4 打印重做；条码页单屏化 |
| **重点页面重排** | 快递比价、空运计费重、阶梯佣金、货币符号、节假日、汇款成本、电压插头、国家信息 |
| **移除站长工具** | 原版「VPS/站长工具」类目（VPS 剩余价值计算器、服务器成本对比）按个人使用原因删除，本站不提供 |
| **品牌化** | 站名、页脚个人 logo、邮件签名默认模板改为 Vera 品牌 |
